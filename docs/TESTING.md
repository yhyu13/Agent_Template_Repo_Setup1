# 验证分级

按「改动是否依赖真实的时间、网络、设备」定级别，能低不高：

| 级别 | 名称 | 适用 | 形态 |
|---|---|---|---|
| L1 | 静态 | 纯语法/类型/格式改动 | lint / typecheck |
| L2 | 行为 | 有逻辑变更，不依赖外部环境 | 单测/集成测试 |
| L3 | 构建 | 动了构建链、依赖、入口 | 本地完整 build（*CI 绿不等于能构建*） |
| L4 | 真实环境 | 依赖真机、真实网络、真实数据 | 一次性环境 e2e + 人工验收 |

DELETED-ON-PURPOSE: 本模板不内置 e2e 框架选型——各项目差异太大，强行给一个只会是错的。
